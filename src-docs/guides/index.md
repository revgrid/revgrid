This section contains practical implementation guides that complement architecture and API reference docs.

Recommended learning path:

1. Create a grid using `client-grid`, `grid-definition`, and `grid-options`.
1. Choose server families (`data-row-array`, `record`, or `sourced-field`) based on your data model.
1. Apply settings implementations and register painters/editors.
1. Add UI-controller customizations and behavior hooks for application-specific workflows.

For exhaustive symbol/member documentation, use the generated API Reference pages.
