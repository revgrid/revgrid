Revgrid libraries provide precomposed building blocks on top of core client/server primitives.

1. [Standard](./standard/index.md): production-oriented painters, editors, and server services.
1. [Simple](./simple/index.md): convenience grid wrappers and settings for rapid use.
1. [JavaScript](./javascript/index.md): non-generic wrappers for JavaScript-first usage.

Libraries are optional layers; applications can consume core APIs directly or adopt these abstractions incrementally.
