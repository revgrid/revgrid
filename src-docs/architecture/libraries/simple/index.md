title: Simple Grids
---

The Simple library provides convenience grids and settings wrappers for quick adoption.

It is ideal when you want a practical default stack with minimal setup while still retaining compatibility with core client/server APIs.

As requirements grow, applications can gradually replace simple defaults with standard or custom implementations.
