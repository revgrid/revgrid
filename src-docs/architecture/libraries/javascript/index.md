---
title: JavaScript Grids
---

The JavaScript library exports wrappers designed for JavaScript-first consumers.

These wrappers reduce generic complexity and provide approachable entry points while preserving the same runtime behavior as TypeScript-focused APIs.

Use this layer when integrating Revgrid in projects that do not rely on deep compile-time typing.

## Primary Public Symbols

1. {@link js/in-memory-settings-client-grid!RevInMemorySettingsClientGrid:class RevInMemorySettingsClientGrid}
1. {@link js/symbol-table-grid!RevSymbolTableGrid:class RevSymbolTableGrid}

These classes provide JavaScript-oriented entry points while delegating core behavior to the same client/server architecture documented elsewhere.
