The Standard library packages reusable defaults for common grid workflows.

It includes:

1. [Standard Cell Painters](./cell-painters/index.md).
1. [Standard Cell Editors](./cell-editors/index.md).
1. [Standard Sourced Field Custom Headings Service](./sourced-field-custom-headings-service/index.md).
1. [Standard Table Field Source Definition Caching Factory Service](./table-field-source-definition-caching-factory-service/index.md).

These modules are intended to reduce boilerplate while keeping extension points open.
