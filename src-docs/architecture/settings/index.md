Settings define behavior, interaction, and visual defaults used throughout the grid lifecycle.

The settings documentation is split into:

1. [Client Setting Interfaces](./client/index.md): public contracts for settings shape and behavior.
1. [Client Implementation Settings](./client-implementation/index.md): concrete default, readonly, and in-memory implementations.
1. [Simple Settings](./simple/index.md): extensions used by the simple library layer.

For exhaustive symbol/member documentation, use the API Reference modules under `client/settings/*`, `settings-implementations/*`, and `simple/settings/*`.
