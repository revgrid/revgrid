The Common module contains contracts and utility types shared by client, server, and library layers.

It is split into:

1. [Server Interfaces](./server-interfaces/index.md): runtime contracts implemented by schema/data/meta providers.
1. [Types and Utilities](./types-utils/index.md): shared value objects, enums, helper functions, and reusable type aliases.

For full symbol-level API details (interfaces, enums, constants, classes and member signatures), see the generated API Reference section for `common/*` modules.
