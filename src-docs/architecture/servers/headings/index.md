---
title: Headings Server
---

Headings servers provide the schema and display values for heading rows.

Revgrid includes single-heading and multi-heading implementations. Multi-heading variants support grouped or hierarchical headings where one visual heading may span several data fields.

Heading servers are often composed with data servers so heading and body structures evolve together.
